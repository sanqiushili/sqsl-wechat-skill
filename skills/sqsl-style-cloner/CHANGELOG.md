# 更新日志 (Changelog)

所有关键版本的更新与重要变更都会记录在此文件中。
版本号遵循 [语义化版本规范 (SemVer)](https://semver.org/lang/zh-CN/)。

## [v1.0.0] - 2026-09-03

### 🚀 初始版本发布 (Initial Release)
- **公众号排版逆向引擎**：支持直接输入公众号文章 URL 或本地 HTML 片段，自动提取视觉 DNA；
- **色彩模型与模式识别**：自动归一化提取主标题色、强调点缀色、正文文字色、引言卡底色与边框色；
- **自动编译与注入**：自动生成符合 `BaseStyle` 规范的 Python 风格类，并无缝注入 `sqsl-article-to-wechat/styles/` 风格池；
- **视觉规范验收页**：生成色板卡与组件预览 HTML，方便用户直观验收复刻效果；
- **一键包管理与新手引导**：支持 `npx skills add` 安装，并内置「使用引导」意图承接。
