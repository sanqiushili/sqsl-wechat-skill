# 更新日志 (Changelog)

所有关键版本的更新与重要变更都会记录在此文件中。
版本号遵循 [语义化版本规范 (SemVer)](https://semver.org/lang/zh-CN/)。

---

## [v1.0.0] - 2026-09-02

### 🚀 初始版本发布 (Initial Release)
- **多风格排版架构 (Multi-Style Registry)**：
  - 内置 **Editorial 先锋大刊风 (`editorial`)**：搭载 Didot/宋体 双向交错渐变水印章节标题图层（无头 Chrome 动态生成）、88% 优雅留白图片卡片、重点引言卡与墨蓝/琥珀橙质感配色；
  - 内置 **阿芋·草木山野生活大刊风 (`olive_artisan`)**：Bodoni 艺术大数字插图图层（01/02）、黄绿胶带高亮大标题、温润燕麦米灰卡片与 1.8 舒适呼吸行高；
  - 模块化风格注册机制（`STYLES_REGISTRY`），方便随时扩展与插拔新风格。
- **正文首图自适应封面 (First-Image-as-Cover)**：
  - 自动扫描并提取 Markdown / HTML 中的第一张插图（支持本地路径、网络 URL 自动下载、Base64 自动解码）；
  - 自动将首图上传至微信永久素材库获取 `thumb_media_id` 作为 900×383 头条封面；
  - 支持 `--cover` 参数手动指定覆盖；
  - 文章无图时自动使用无头 Chrome 渲染艺术渐变标题头条封面兜底。
- **全自动微信 CDN 图床转存**：
  - 自动扫描 HTML 正文所有图片与 Base64 图层，调用 `media/uploadimg` 上传微信官方 CDN 并替换为 `mmbiz.qpic.cn` 链接。
- **微信官方草稿箱云端直推**：
  - 调用公众平台官方 `draft/add` 接口一键直推后台草稿箱，手机端公众平台助手一键审核群发。
- **本地双模预览与一键复制**：
  - 每次排版同步生成带磨砂悬浮药丸工具栏的本地 HTML 预览页，支持一键无损复制到剪贴板。
- **通用 Markdown 语法全覆盖**：
  - 深度支持代码块（深色容器）、表格、Quote 引用块、有序/无序列表、高亮标注 `==mark==` 与行内代码。
